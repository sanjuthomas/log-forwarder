# Support

How to get help with **log-forwarder** without opening the wrong kind of ticket.

## Documentation

| Resource | Use for |
|----------|---------|
| [GitHub Wiki](https://github.com/sanjuthomas/log-forwarder/wiki) | Install, configuration, sinks, watermarks, monitoring, deployment |
| [README](README.md) | Quick start and wiki index |
| [CHANGELOG](CHANGELOG.md) | What changed between versions |
| [Example configs](configs/) | Copy-paste YAML starting points |
| [AGENTS.md](AGENTS.md) | AI agent / advanced contributor conventions |

## Community

| Channel | Use for |
|---------|---------|
| [GitHub Discussions](https://github.com/sanjuthomas/log-forwarder/discussions) | Questions, ideas, show-and-tell — **start here** if unsure |
| [Bug report](https://github.com/sanjuthomas/log-forwarder/issues/new?template=bug_report.yml) | Something broken or behaving unexpectedly |
| [Feature request](https://github.com/sanjuthomas/log-forwarder/issues/new?template=feature_request.yml) | New capability or enhancement |
| [Documentation issue](https://github.com/sanjuthomas/log-forwarder/issues/new?template=documentation.yml) | Wiki, README, or config docs are wrong or missing |

## Security

Do **not** use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md)
and report via [GitHub Security Advisories](https://github.com/sanjuthomas/log-forwarder/security/advisories/new).

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the PR workflow, CI checks, and coding guidelines.

## Commercial / private support

This is a community-maintained MIT project. There is no paid support tier today.
Maintainers respond on a best-effort basis via GitHub.
